# Support

## Getting Help

This is a learning lab for Microsoft Foundry hosted agents. Support is available through the resources below.

### GitHub Issues

For bugs, questions, or feature requests about this learning lab, [open an issue on GitHub](https://github.com/Azure-Samples/foundry-hosted-agents-dotnet-demo/issues).

- Search existing issues first to avoid duplicates
- Provide a clear description of your problem or question
- For bugs, include reproduction steps and relevant error messages
